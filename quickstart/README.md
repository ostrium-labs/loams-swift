# quickstart

Runs the 0.1.2 SDK module tour against `examples-swift`: system and instance discovery, namespace and collection creation, document reads/writes, text/vector/hybrid search, optional graph, SDK SQL and streams. Stable document IDs and stream producer keys make reruns safe.

```sh
export LOAMS_ENDPOINT=http://127.0.0.1:8080
swift run quickstart
```
